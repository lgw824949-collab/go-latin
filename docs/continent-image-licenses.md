## 적용 기준

- Nomads.com은 참고만 하며 이미지·코드·디자인 자산을 무단 복제하지 않는다. 검색 결과, 블로그·뉴스·여행사·호텔·SNS 사진도 이용허락 없이 사용하지 않는다.
- 실제 촬영 여부, 원본 게시 페이지, 권리자, 상업적 이용 및 수정·크롭·리사이즈·최적화 허용, 출처 의무와 제3자 권리를 개별 확인한다.
- Editorial Only, 비상업용, 유료, 워터마크, 출처·권리자 불명확, 필요한 초상권·상표권 등 허락 미확보 자료는 제외한다.
- 출처 표기나 사용자 제공 사실만으로 이용허락을 추정하지 않는다. AI 생성·합성 여부가 확인되지 않으면 실사로 승인하지 않는다.
- 무료 적격 사진을 확보하지 못하면 임의 교체·구매·유료 API 사용 없이 현 상태를 유지하고 차단 사유를 보고한다.
- 6개 모두 증빙을 갖춘 후에만 새로운 이미지 Preview 적용을 진행한다. Production은 별도 최종 승인 후 진행한다.

## 현재 증거와 한계

- 확인 가능한 취득 경로는 사용자 제공 Downloads 파일이다. 원본 게시 페이지나 권리 양도·라이선스 자료는 확보되지 않았다.
- Downloads 원본과 저장소 보존본 6개 모두 PNG tEXt/iTXt/zTXt/eXIf 청크가 없다. 메타데이터 부재는 무권리나 AI 생성의 증거가 아니라, 이 경로로 출처를 확인할 수 없다는 뜻이다.
- 저장소 최초 추가: 56c48f1 (2026-11-06). 색보정 사본 추가: 8685520 (2026-11-07). Git 날짜는 다운로드 날짜가 아니다.
- web/src/lib/capitalImageCredits.js는 다른 도시 이미지의 URL별 크레딧이다. 현재 6개 PNG의 라이선스 증빙으로 전용하지 않는다.
- web/public/continents-approved/ 원본은 보존되어 있다. web/public/continents-graded/는 해당 파일의 색보정 파생본이며 원본과 동일한 권리 확인이 필요하다.
- 기존 색보정·사진 같은 외관은 실제 촬영 여부 확인을 의미하지 않는다. 현재 Preview는 이전 작업 결과이고 라이선스 검증을 통과한 배포가 아니다. 이번 조사에서는 코드·이미지·기존 Preview·Production을 변경하지 않았다.

각 파일의 실제 사진 원본 페이지·작가, 상업·수정 허용 증빙, 실제 다운로드 일자, 필요한 출처 표시와 제3자 권리 검토 결과를 기록하고 원본과 파일의 대응을 검증한다. 근거가 모호한 파일은 제외한다. 라이선스 확인은 법적 무위험을 보장하지 않는다. 검증 완료 전 추가 이미지 적용 및 Production 승인을 보류한다.

## 2026-11-07 실제 사진 교체 검증

이 문서 앞부분의 보류 판정은 기존 사용자 제공 PNG 6개에 대한 것으로 그대로 유효하다. 새 적용 후보는 별도 Pexels 사진이며 `docs/continent-photo-manifest.json`에 개별 기록을 보관한다. 기존 PNG와 색보정 사본은 삭제하지 않는다.

- Pexels 개별 사진 페이지에서 사진 종류, 작가, 위치, Free 라이선스 및 가능한 카메라·촬영일 정보를 확인했다. Cairo 후보는 카메라·촬영일이 공개되지 않아 그 필드를 미제공으로 기록했다. 해당 페이지의 실제 거리 사진 설명과 시각 검토를 근거로 선정했으며, 메타데이터로 진위를 완전히 입증했다고 주장하지 않는다.
- 공식 라이선스: https://www.pexels.com/license/
- 공식 약관: https://www.pexels.com/terms-of-service/ (페이지 표시 개정일: 2026-10-20)
- 상업 웹사이트의 비독립적 배경 사진 사용과 수정·크롭은 허용된다. Pexels 또는 작가 표시 의무는 없지만 이미지 title과 개별 기록에 작가를 보존했다.
- 사진 원본 다운로드는 각 사진 페이지의 Free download 링크를 사용했다. 검색 결과 미리보기나 Nomads.com 자산을 복제하지 않았다. 원본은 작업 산출물 폴더 `continent-real-photos/`에 보존하며 원본 SHA-256·배포 파일 SHA-256·실제 다운로드 날짜·크롭 좌표를 manifest에 기록했다.
- 소스 JPEG에는 EXIF 카메라 정보가 포함되지 않았다. 카메라·촬영일 기록은 공개 사진 페이지의 정보을 옮긴 것이며 파일 EXIF 판독 결과와 혼동하지 않는다.
- AI 생성·합성·추가 색보정·인물 삭제·리터칭은 수행하지 않았다. 고품질 bicubic 크롭/리사이즈와 JPEG quality 86 저장만 수행했다. 서울은 원본 그대로의 해질녘 야경이며 완전히 검은 밤으로 인위 변환하지 않았다.
- Barcelona는 전면 인물·상점 브랜드가 있는 첫 후보를 제외하고 골목 건축 중심 사진으로 교체했다. 좌측 벽화가 큰 영역은 크롭에서 제외했다. 원거리 행인은 주된 피사체가 아니다.
- Cairo는 기념품·장식품 자체가 주인 첫 후보를 제외하고 역사적 건물과 시장 거리의 광경으로 변경했다. 작은 배경 행인·점포는 도시 맥락이며 인물 추천·상점 제휴를 나타내지 않는다.
